# Импорт пользователей PSN HUB

Импорт нужен, чтобы доступ к платформе получали только пользователи из CRM-выгрузки. Логин берется из CRM, а если поле `Логин` пустое, используется ФИО пользователя. Общий актуальный код меняется администратором.

## Формат файла

Поддерживаются Excel `.xlsx/.xls` и CSV/TSV с разделителем `;`, `,` или табуляцией. Обязательное поле: `id`. Для входа используется `login`, а если он пустой — `name`/ФИО из имени и фамилии. Скрипт понимает как `CSV UTF-8`, так и обычный CSV из Excel в кодировке Windows-1251.

```csv
id;login;name;email;phone;status
1001;ivanova anna;Анна Иванова;anna@example.com;+77000000001;active
1002;petrov ivan;Иван Петров;ivan@example.com;+77000000002;active
1003;sidorova maria;Мария Сидорова;maria@example.com;+77000000003;архив
```

Можно использовать русские заголовки: `ид`, `логин`, `фио`, `почта`, `телефон`, `статус`.

CRM-выгрузка может содержать служебные строки сверху, например название отчета и дату создания. Скрипт сам ищет строку заголовков, поэтому изменение даты выгрузки в названии файла или в шапке отчета не влияет на импорт.

Если передать в команду папку, а не конкретный файл, скрипт возьмет самый свежий XLSX/CSV/TSV из этой папки. Это удобно, когда дата каждый раз меняется в названии файла.

## Что делает импорт

- Создает или обновляет пользователей в Firebase Authentication.
- Записывает карточки пользователей в Firestore `accessUsers`.
- Ставит всем пользователям новый недельный код.
- Может архивировать тех, кого больше нет в новой выгрузке.
- Не создает пользователей, у которых в выгрузке стоит `Заблокирован = 1/да/true`.

## Команда

В PowerShell из папки проекта:

```powershell
$env:GOOGLE_APPLICATION_CREDENTIALS="C:\Users\ROG STRIX\Documents\Firebase Keys\travel-edu-app-firebase-adminsdk-fbsvc-083d82bfe8.json"
$env:PSN_HUB_WEEKLY_CODE="сюда-вставить-новый-код-12-символов-или-больше"
npm run sync:users -- "C:\путь\к\выгрузке-users.xlsx"
```

Перед настоящим импортом можно сделать безопасную проверку без записи в Firebase:

```powershell
npm run sync:users -- "C:\путь\к\выгрузке-users.xlsx" --dry-run
```

Чтобы архивировать пользователей, которых нет в свежей выгрузке:

```powershell
npm run sync:users -- "C:\путь\к\выгрузке-users.xlsx" --archive-missing
```

## Важно

Код не хранится открыто в интерфейсе. После импорта его можно опубликовать в новости CRM, а пользователи входят по своему CRM-логину и этому коду.
