# Синхронизация пользователей CRM

Выгрузка обрабатывается только локально. Не загружайте ее в админку, GitHub,
Google Drive или этот чат. Пароли пользователей из CRM для PSN HUB не нужны.

## Колонки файла

Поддерживается CSV/TSV с заголовками на русском или английском:

- `ID` — постоянный ID пользователя CRM;
- `Логин`;
- `ФИО`;
- `Email`;
- `Телефон`;
- `Статус` — необязательно.

## Первый запуск

1. В Firebase Console создайте сервисный ключ администратора.
2. Храните JSON-ключ вне папки проекта.
3. Один раз установите пакет: `npm install --save-dev firebase-admin`.
4. Укажите путь к ключу в `GOOGLE_APPLICATION_CREDENTIALS`.
5. Сгенерируйте недельный код в разделе `Админ-панель → Пользователи`.
6. Передайте его процессу через `TRAVEL_EDU_WEEKLY_CODE` и запустите импорт.

Пример для PowerShell:

```powershell
$env:GOOGLE_APPLICATION_CREDENTIALS="C:\secure\travel-edu-admin.json"
$env:TRAVEL_EDU_WEEKLY_CODE="EDU-XXXX-XXXX-XXXX"
node scripts/sync-crm-users.mjs "C:\secure\crm-users.csv"
```

Флаг `--archive-missing` блокирует и архивирует учетные записи, которых нет в
текущей выгрузке. Используйте его только для полного отчета по всем сотрудникам.

Скрипт назначает недельный код всем активным пользователям, но не записывает его
в Firestore и не выводит в консоль. Firebase Auth принимает код по защищенному
соединению и хранит только его хеш. После успешной синхронизации код можно
опубликовать в закрытой новости CRM.
