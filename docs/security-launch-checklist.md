# Первый запуск закрытого PSN HUB

## 1. Проверка администратора

Убедитесь, что в Firebase Authentication существует пользователь
`psnkzeducation@gmail.com` с входом Email/Password. Эта учетная запись остается
доступной даже до импорта CRM.

## 2. Импорт пользователей

Выполните действия из `docs/crm-users-sync.md`. Для первого запуска не
используйте `--archive-missing`. После импорта откройте вкладку
`Админ-панель → Пользователи` и проверьте количество записей.

## 3. Публикация правил Firestore

После успешного импорта опубликуйте `firestore.rules` в проект
`travel-edu-app`:

```powershell
npx firebase-tools login
npx firebase-tools use travel-edu-app
npx firebase-tools deploy --only firestore:rules
```

## 4. Контрольная проверка

1. Выйдите из учетной записи администратора.
2. Войдите под одной тестовой учетной записью из CRM, используя недельный код.
3. Проверьте открытие вебинара, документа и обучающего трека.
4. В админке заблокируйте тестового пользователя.
5. Обновите страницу под тестовым пользователем: каталог должен закрыться.

## Что уже защищено кодом

- материалы и треки читают только активные пользователи;
- архивный или заблокированный пользователь теряет доступ;
- администраторские изменения разрешены только основной почте администратора;
- сессия завершается через 12 часов;
- поисковая индексация отключена через metadata, robots.txt и X-Robots-Tag;
- недельный код не записывается в Firestore и не показывается после закрытия окна;
- секретные CRM-выгрузки и сервисные ключи исключены из Git.

Внешний календарь `learningagenda.netlify.app` имеет собственный публичный адрес.
Вход PSN HUB защищает только встроенное открытие календаря, но не прямой
переход на этот внешний адрес. Для него нужна отдельная защита в проекте Netlify.
